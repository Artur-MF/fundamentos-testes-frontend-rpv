Erros:

1. Botão de marcar concluído não exibe que concluiu.
2. Botão Excluir n remove as tarefas da tela.
3. Botão adicionar adiciona uma tarefa mas ela não é exibida, e é removida logo depois de ser adicionada na quantidade total de tarefas.
4. Quando clica para concluir uma tarefa, o número de tarefas concluídas não é atualizado. A menos quando todas são concluídas, nesse caso exibe 3 tarefas concluídas.
5. Botão concluídas não muda nada.
6. Tarefas pendente aparece 0 ou 3 sempre.
7. Ordenar por prioridade não muda nada.
8. Buscar tarefas não tem tratamento para diferentes formatações.
9. Ao clicar no botão excluir quando 3 tarefas estão concluídas, ele deixa as tarefas pendentes negativas.
10. A contagem de tarefas em baixo não estão sincronizada.
